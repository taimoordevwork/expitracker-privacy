# ExpiTracker — Privacy Policy

The published privacy policy for the Android app **ExpiTracker**
(`com.expitracker.app`), served via GitHub Pages so the Play Console listing
has a stable public URL.

`index.html` is the page. The canonical source lives with the app, in
`store-assets/privacy-policy/index.html` — edit it there and copy it here, so
the two cannot drift.

The app is offline-only: it declares no `INTERNET` permission, so it cannot
transmit anything. The policy explains what that means in practice.
